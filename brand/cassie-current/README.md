# Cassie Current Brand Export

Exported from the current web app version.

## Assets

- `cassie-logo-glow-black.png` - primary logo export: the rendered web app logo with the exact CSS filter and glow baked onto a black 1254x1254 background.
- `cassie-logo-glow-black@2x.png` - 2x primary logo export.
- `cassie-logo-glow.png` - transparent-background version on the same 1254x1254 canvas as the source mark.
- `cassie-logo-glow@2x.png` - 2x transparent-background version.
- `cassie-logo-transparent.png` - source app mark.
- `colors.css` - current app color tokens plus the logo filter/glow treatment.
- `colors.json` - OKLCH source tokens with approximate hex/RGB values.
- `preview.html` - local preview of the logo treatments and palette.

## App Logo Treatment

The primary exported version is `cassie-logo-glow-black.png`. It uses the rendered homepage logo treatment with the same CSS filter and drop-shadows used by the web app.
